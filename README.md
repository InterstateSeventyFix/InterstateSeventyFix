# Interstate SeventyFix

**Yet another unofficial enhancement project for Activision's Interstate '76.**

Interstate SeventyFix is a fan-developed project dedicated to improving the classic 1997 vehicular combat game *Interstate '76*, while preserving the character and gameplay of the original. The original game has a lot of charm, but it also has more bugs than a beehive and is infamous for running poorly on modern computers. The goal is to fix all of that and add modern features.
<br><br>

## Uniqueness

What sets Interstate SeventyFix apart from other projects that share the same goal? We are climbing the same mountain but taking different routes to the top. Interstate SeventyFix is not a remake, nor does it use hooks or runtime machine-code patches to modify the game. Interstate SeventyFix is based on a reassemblable disassembly of i76.exe. The source can be edited and reassembled and tested in a debugger with relative ease. But the source is not easy to read or understand. Variables and subroutines have generic names like "var_D4" and "sub_41B270". Figuring out what they mean and what they do is a reverse engineering challenge.
<br><br>

## Features

- **High framerates** without the fluttering wheels, misfiring flamethrowers and mortars, malfunctioning ramps, racing clouds, etc.
- **High-resolution software rendering** with widescreen and aspect ratio correction.

## Installation

To install, follow the steps in the README file that is included in the download.

**Users must supply their own copy of Interstate '76.**

The current release of Interstate SeventyFix patches **Interstate '76 Gold Edition**.

 **Interstate '76 GOG Edition** can be patched, but may be unplayable because it will prompt you to insert the game CD.  See **Issues** for a workaround.
